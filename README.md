## Experiment 10: Building a Simple LLM Chatbot Using Streamlit/Gradio

This experiment focuses on building a simple chatbot using a pretrained Large Language Model (LLM) with Python, Hugging Face Transformers, and Gradio. The pretrained DistilGPT2 model is loaded to generate text responses based on user prompts. A response generation function is created to process user input and display the generated text. Gradio is used to develop an interactive chatbot interface where users can enter messages and receive responses. The chatbot is tested using different prompts to evaluate its response quality and relevance. This experiment helps in understanding the basic working of LLMs, prompt handling, text generation, and the development of interactive AI applications.

**Conclusion:** Thus, a simple LLM-based chatbot was developed and tested successfully using Python, Hugging Face Transformers, and Gradio.
